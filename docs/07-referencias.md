# Referências e caminhos para aprofundar

Fontes consultadas em 3 de outubro de 2026. As especificações da placa vêm do fabricante. As escolhas de arquitetura e os marcos são propostas do projeto.

- [Sipeed — Tang Nano 20K](https://en.wiki.sipeed.com/hardware/en/tang/tang-nano-20k/nano-20k.html): recursos, interfaces e documentação da placa.
- [IBM — Single systems](https://learning.quantum.ibm.com/course/basics-of-quantum-information/single-systems): estados, amplitudes e operações.
- [IBM — Multiple systems](https://learning.quantum.ibm.com/course/basics-of-quantum-information/multiple-systems): sistemas compostos e entrelaçamento.
- [IBM — Statevector](https://quantum.cloud.ibm.com/docs/en/api/qiskit/qiskit.quantum_info.Statevector): possível referência independente para uma etapa futura de comparação.

O projeto não é afiliado à Sipeed ou à IBM. A implementação inicial não depende do Qiskit.
