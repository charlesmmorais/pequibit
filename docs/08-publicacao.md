# Preparação para o GitHub

Repositório: https://github.com/charlesmmorais/pequibit.

Descrição sugerida: “Laboratório educativo de simulação quântica em FPGA. Aprenda com circuitos pequenos e construa um executor para a Tang Nano 20K.”

Tópicos sugeridos: `quantum-computing`, `quantum-simulation`, `fpga`, `tang-nano-20k`, `systemverilog`, `education`, `portuguese`.

## Antes da primeira publicação

- Nome do repositório definido: `charlesmmorais/pequibit`. Isso não constitui registro de marca.
- Revisar autoria e selecionar licença. Proposta: Apache-2.0 para software/RTL e CC-BY-4.0 para documentação, com avisos e arquivos completos antes da publicação. Esta base não inclui concessão de licença e ainda não deve ser anunciada como open source.
- Executar os quatro exemplos e os testes; manter explícito que o RTL não está implementado.
- Criar o repositório e enviar os arquivos, preservando a pasta `.github` para os testes automáticos.
- Publicar M0 como base educativa, sem anunciar um processador FPGA já funcional.

Este documento acompanha a publicação da base educativa. O estado de cada implementação está no README e no roadmap.

## Modelo de release inicial

Pequibit — base educativa inicial. Inclui um modelo de vetor de estado em Python, quatro experimentos, testes automáticos e arquitetura proposta para a Tang Nano 20K. O próximo marco é reproduzir a aritmética de ponto fixo antes da implementação RTL.
