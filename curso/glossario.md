# Palavras que vamos usar

| Termo | Significado neste curso |
|---|---|
| Bit | Valor clássico 0 ou 1 |
| Qubit | Sistema quântico de dois níveis; aqui representado matematicamente |
| Amplitude | Coeficiente complexo de um estado da base |
| Probabilidade | Módulo ao quadrado da amplitude para uma medição nessa base |
| Fase relativa | Relação de fase entre componentes que pode afetar interferência |
| Fase global | Fator de fase comum a todo o vetor, sem efeito observável |
| Superposição | Combinação linear de estados de uma base |
| Entrelaçamento | Estado conjunto que não se separa em estados individuais; aqui tratamos estados puros |
| Porta | Transformação unitária aplicada ao estado ideal |
| Medição | Operação que produz um resultado clássico e atualiza o estado condicionado a ele |
| Pós-seleção | Análise ou seleção de um resultado específico, ponderado pela sua probabilidade |
| Oráculo | Operação que codifica a regra do problema |
| Fidelidade | Medida de concordância de estados; vale 1 para concordância perfeita |
| FPGA | Hardware digital reconfigurável |
| RTL | Descrição de transferências e operações entre registradores |
| Ponto fixo | Inteiros interpretados com uma escala numérica definida |
